1. Float

Properti float digunakan untuk membuat elemen seperti gambar berada di sisi kiri atau kanan sehingga teks dapat mengalir mengelilinginya.

Sebelum Flexbox dan Grid populer, float sering digunakan untuk membuat layout website. Saat ini float lebih sering digunakan untuk mengatur posisi gambar di dalam artikel.
