HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk membuat struktur halaman web. Dengan HTML, kita dapat membuat heading, paragraf, gambar, tabel, formulir, dan berbagai elemen lainnya.


Link atau hyperlink digunakan untuk menghubungkan satu halaman dengan halaman lain. Link juga dapat mengarah ke website lain, file, alamat email, maupun bagian tertentu dalam halaman yang sama.

Atribut href digunakan untuk menentukan tujuan link. Sedangkan atribut target="_blank" digunakan agar halaman tujuan dibuka pada tab baru di browser.

Selain menuju website lain, HTML juga mendukung navigasi di dalam satu halaman menggunakan atribut id. Hal ini sangat berguna untuk halaman yang memiliki konten panjang.

Contoh lain penggunaan link adalah membuka aplikasi email menggunakan mailto:. Saat link diklik, aplikasi email akan terbuka dengan alamat tujuan yang sudah terisi.

Teruslah berlatih membuat berbagai jenis link agar lebih memahami cara kerja navigasi dalam HTML. Penguasaan dasar ini sangat penting sebelum mempelajari CSS dan JavaScript.
